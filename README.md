# Mohammed Sinan C – Data Analyst Portfolio

An interactive, dark-and-white themed Data Analytics Portfolio replicated to match the design, layout, animations, typography, and interactive behaviors of [mohammed-irfan.vercel.app](https://mohammed-irfan.vercel.app/), customized with the credentials, professional experience, skills, and projects of **Mohammed Sinan C** extracted from his resume.

---

## 🚀 Features & Replicated Theme

- **Interactive Fluid Blob Cursor**:
  - Trailing organic fluid cursor morphing via `@keyframes blob`
  - Real-time mouse velocity tracking with dynamic elongation, angle rotation, and spring acceleration
  - Sharp central tracking dot with `mix-blend-difference`
- **Buttery Smooth Scrolling**:
  - Powered by **Lenis** smooth scroll engine for inertia-driven scroll physics.
- **Fixed Navbar**:
  - Transitions automatically based on scroll depth with backdrop blurring.
  - Smooth navigational anchors to `#projects`, `#profile`, `#experience`, and `#contact`.
- **Hero Section**:
  - Playful "Easter egg" top caption.
  - Letter-by-letter hover physics on **Mohammed Sinan C** (spring expansion and elevation).
  - Dynamic cycling subtitle role carousel ("Data Analyst", "BI & Dashboard Specialist", "Data Storyteller", "Python & SQL Developer", "Machine Learning & AI Enthusiast").
  - Signature curved white bottom card (`rounded-b-3xl md:rounded-b-4xl`).
- **Works Bento Grid (`#projects`)**:
  - Pure black background with crisp white typography.
  - Entrance letter animation for **"My Works."**
  - 4 high-impact data analytics & AI projects arranged in an asymmetric Bento Grid:
    1. **Fracture Detection System – AI Diagnostic Vision** (Featured Deep Learning / Computer Vision project from resume)
    2. **Executive Business Intelligence & KPI Suite** (Power BI, DAX, SQL, Power Query)
    3. **Automated Data Ingestion & ETL Pipeline** (Python, MySQL, Pandas, automated reporting)
    4. **Predictive Customer Churn & LTV Modeling** (Machine Learning, Tableau, Statistics & Probability)
  - Interactive cards with zoom overlays, technology badge pills, and direct GitHub / Demo action icons.
- **About Me Section (`#profile`)**:
  - Monolithic typography (`About` and massive `Me.`).
  - Narrative blocks for **Who Am I**, **What I Do** (interactive skill badges), and **Outside the Terminal** (analytical mindset).
  - Educational background (**Computer Science**, Majlis Arts & Science College, Valanchery, Kerala) and multilingual proficiency (**English, Hindi, Arabic, Malayalam**).
- **Interactive Experience Timeline (`#experience`)**:
  - Dynamic SVG cubic Bezier curve that traces progress on scroll.
  - Glowing traveling indicator bead that rides the curve in real time.
  - Professional milestones:
    - **Data Analyst Intern** at TechnoDot Academy, Kinfra, Kakkanchery (07/2026 – Present)
    - **Junior Software Developer** at Region Technologies, Calicut, Kerala (08/2025 – 03/2026)
- **Contact Section (`#contact`)**:
  - Giant **"Where to find me."** header featuring the authentic `.flicker` neon text animation.
  - Direct mail link to `mohammedsinan_c@outlook.com`.
  - Direct call button (`+91 9539778302`), GitHub, LinkedIn, and Resume PDF download buttons.

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion + CSS Keyframes
- **Smooth Scroll**: Lenis
- **Icons**: Lucide React
- **Typography**: Playfair Display + Inter

## 💻 Getting Started

### Prerequisites
- Node.js (v18+)

### Development Server
```bash
npm run dev
# Or on Windows PowerShell:
npm.cmd run dev
```

### Production Build
```bash
npm run build
# Or on Windows PowerShell:
npm.cmd run build
```

Preview the build locally:
```bash
npm run preview
# Or on Windows PowerShell:
npm.cmd run preview
```
